# 分层、运动与稳定完成态

## 重建原则

完成态 PNG 是布局参照，不是整页动画素材。优先从文档的 editable 提取真实 text/path/rect/image/g；引用相同背景、字体、插画。明确语义组，不把整页包装成一个淡入层。缺少字形、透明资产或可编辑数据时列出缺项，代理用确定性文字/图形复原，保留原 PNG 对照。不要覆盖输入源。

一个独立素材（照片、插画或背景）可以是位图；文字、数字、数据图和荧光笔不能因为采用位图素材就一起烘焙。同版稳定完成态需和批准 PNG 比较；有意差异只限于入场过程，不能随意改定稿位置、比例或字体。

## 事件接口

附带渲染器读取分镜源 SVG 的 `g[data-at]`，`data-at` 为源音频绝对毫秒，`data-until` 可选，表示该语义组退出时刻。所有可见元素归属于独立语义组，背景/风格定义除外。默认入场 240 ms；`data-duration` 可覆盖。`data-motion="hold"` 或镜头起点及此前存在的组立即保留，不重新入场。事件锚点必须来自文档、SRT 和已核实口播，不是按字数计算。

如果源没有这些标记，渲染器明确失败。代理应在本轮输出目录按语义重建并标记 SVG，生成内部 manifest 的 source 适配副本与变更记录；不要求用户填写表。若一个组含多条逐项口播，拆成子语义组并分别给锚点，不能一个大组一起出现代替逐项讲解。

## 各层运动

- 背景：从第一帧稳定存在，不做全页淡入或推拉，不叠滤镜。
- 文字/数字/卡片/插画：克制的独立显现；默认不滚动金额、不制造原文不存在的中间数字。需位移时围绕定稿坐标小幅收敛，完成态位置精确回到定稿。
- 连续图表：保留已出现的点、轴、标签，只描新增线段/柱/点。绘制顺序按因果或数据顺序；不让已有路径因换镜重画。不可通过抖动、呼吸或无限缩放填空档。
- 箭头：仅在关系已讲到时出现，描线不能穿文字；箭头头部应与线端对应，不先显示一个漂浮箭头头。
- 荧光笔：`data-role="emphasis"` 的独立路径用水平裁切从左向右涂出；不改变原颜色/透明度，不缩放文字，完成后移除裁切以保持定稿。黑字可先出现，黄色不是全组淡入替代。
- 退出/切页：背景和新镜开场内容无黑帧空档。允许语义上真实的停留，不用循环动效填充；结论不能在口播前露脸。独立观点到图表的重排需明确记录路径和时机，连续数据图本身不抖动或逐帧自动居中。
- 实拍：按文档视频映射绝对取帧，原色与定稿裁切，源视频静音，不添加动画字幕，不定格、循环或变速补时长。此路径默认支持相同 16:9 全幅缩放；其他裁切需代理显式适配，不猜。

## 帧状态

对每一输出帧只使用绝对时间算状态，不依赖前一帧、墙钟、随机数或 CSS 动画累计时间。同一个源时间从全片或中途区间渲染，像素必须一致。测试先 seek 后退再前进，应可复现；入场开始、半程、稳定和切页前后都保存代表帧。
