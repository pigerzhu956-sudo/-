# 视觉与可编辑交付

## 纸张、字体与颜色

- 1920 × 1080；左右安全边距 96 px，上下 72 px。不靠缩字号塞内容。
- 静态设计页固定 `../assets/newsprint-blue-gray.png`：基调 #C9DCE5，低对比纸纤维、细微磨损、印刷颗粒，无文字、重折痕、明显暗角。位于 (0,0)，原尺寸 1920 × 1080，逐页复用同一哈希。实拍页自然原色满屏，不套纸张或全屏滤镜；文字安全区不限制实拍的自然满幅影像。
- 标题粗宋体 Songti SC，正文 PingFang SC，英文和大数字 Georgia；缺少时选思源宋体／Noto Serif SC、思源黑体／Noto Sans SC 等对应字形，记录实际字体、字重、文件路径，CSS 回退列表不等于安装证据。宋体标题不能落到黑体。
- 标题约 72 px、正文 34–42 px、必要辅助字 27–30 px，作为起点。中文与相邻数字留一个半角空格，美元写 `$200`，其他币种按原文。只规范上屏字，不改 SRT 或逐字原文。
- 墨黑 #17191B、次级灰 #555A5E、强调红 #9E2730、荧光黄 #E6F01F。

## 内容驱动构图

先确定本镜对象、动作、变化和关系，写出媒介决策，再排版。每镜集中一个理解任务，用 1–2 种主要手法；全片变化按语义产生，不强制素材比例。标题可省略，不重复标题、主体和底部总结。内容组按实际可见轮廓平衡居中，不按透明图像边界机械居中；主体需足够大，组内紧凑、组间留白，同级对象等距。禁止模板页眉、页码、角落标签、装饰小字，不用缩字、胶带或小图标填空。

| 理解任务 | 优先媒介与必要条件 |
|---|---|
| 价格变化 | 有数据口径的走势；仅连接已知节点 |
| 数量比较 | 同尺度柱图、阵列或重复物件，单位一致 |
| 金额组成 | 分段图、共同基线的组成柱，分母明确 |
| 交易动作 | 资金与份额物件、人物交付动作，具体解释换取关系 |
| 时间、金额、自动规则 | 同系列语义图标配短标签，实际获取资产 |
| 实际操作 | 可核实的真实界面，不生成假账户或假截图 |
| 思考、研究、等待 | 主动搜索并观看免费实拍；不合适则制作具体场景插画 |
| 对账、观点或引用 | 账本、剪报，避免每句话装框 |

上屏字保留关键数值、单位、否定、条件，删除重复口播的长句；原文区完整逐字保留。周期/阶段用时间轴，因果/条件用流程，并列用对比，可靠数值才用图表，观点/引语可用剪报，人物处境可用场景插画。变化来自内容，不为凑样式编数字、加无关图标或强塞图表。开场只呈现此时已讲到的信息。

## 方框、剪报和图表

流程节点用浅纸色矩形，四边轻微起伏、粗细略异的手绘线，短字居中；不用胶囊或粗黑边，不加撕纸和胶带。暗红箭头只表达真实先后/因果，不穿文字。强调结果节点可暗红底配浅字。

观点/引语卡用灰白纸、克制不规则撕边、少量半透明胶带；不把每句话装框。卡内留白平衡，不压人物脸、手、关键道具。

图表直接画在纸上，绘图区透明，灰轴和少量浅网格；暗红主线约 4–6 px，成本比较可黑虚线，短标签靠近对应数据。柱图同基线；份额阵列与饼/环按真实比例。明确分母、单位、口径；均价 = 累计投入 ÷ 累计份额，不用价格简单平均代替。假设算例必须标注，不能冒充行情；缺可靠数据改用概念表达。

仅有几个已知价格时用直线连接已知节点，不伪造中间波动，不用平滑曲线暗示连续历史。横轴未知时间只标相对事件，不擅自补月份；价格、持仓、市值口径分开。累计完成后的成本基准可以作回顾比较线，须在标签注明形成时点，不能画成之前始终存在的历史成本。连续图共用坐标、比例、已有节点和元素 ID，新信息按口播出现；未来点、成本线、后文结论不得提前揭示。走势图和比例环等各自需要大空间时，用镜内阶段切换，不挤满一页。

## 强调、素材与图层

只强调准确关键短语，同一词组红字和黄笔二选一，不整段涂色。红字保留原字体、字号、基线。黄笔为黑字背后粗荧光涂抹，约 84% 不透明度、边缘稍不规则，不是细下划线或规则黄底框，独立笔刷层。

插画实际调用图像生成工具，可用彩色编辑插画、手绘物件、炭笔、网点或克制立体质感，按辨识度选，同组一致。人物要有对应动作与道具，物件要解释关系；不整片复用通用人物或电脑图。图标、人物、物件分别保存。图标须来自已核实的同系列免费图标集，不用 emoji 或临时拼几何形状代替。中文、数字、公式、数据图与关系箭头使用确定性排版，不能烘焙进生成图。真实 Logo、书封、人物身份、平台、界面必须可核实；未指定具体产品不得自行添加名称或 Logo。独立插画验证真实 alpha，并在棋盘和深浅底检查边缘；无白框、白晕或画出的棋盘底。

推荐逐页 SVG（文字保留 text、图形 path/rect、语义 g），或 HTML/CSS/SVG，也可其他保留层的源。源的字体、链接图片等依赖必须可解析；不能只嵌整张 PNG 冒充可编辑。

背景、文字、数字、图表、连线、卡片、插画、强调分开；图与短标签、卡片与内容按语义分组。黄笔在文字后。手绘线可固定随机种子生成 path，避免重渲染跳动。

连续图表共享坐标、比例、范围、元素 ID，只增加/改变新信息。保留 opening、reveal-01…、complete 可重现状态及入口参数。保存开场、每个关键新增、完成态检查截图路径；完整 PNG 对应 complete。

## 实际验收

逐页打开原尺寸（必要时 100% 分区，不能仅看缩略图），查数字/单位/条件/否定、字形缺字、红字基线、黄笔范围、箭头语义、图形比例、基线/等距/对齐、边距/裁切、整体留白。检查阶段信息的先后、沿用元素，再连续联看全片，发现重复构图、坐标漂移和跳变。

记录每页观察、问题、修正、工具与日期；未做的检查写未完成。最终只称分镜验收，不能声称音画同步通过。

实拍验收还需实际查看所用完整区间及首、中、尾代表帧：主体不裁脸手或关键道具，无买入操作或虚假收益暗示；通用演员不指代创作者本人、真实持仓或背书。正常速度连续覆盖，关闭素材原声，默认不叠解释文字。保存可复现的取帧时间、裁切和缩放参数。
